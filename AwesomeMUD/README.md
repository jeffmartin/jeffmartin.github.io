# Deep Drift

A simple browser-based single-player space exploration MUD prototype built with plain HTML, CSS, and JavaScript.

## How to run

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in the browser.

## Commands

- `look`
- `inventory`
- `take <item>`
- `use <item>`
- `go <direction>`
- `help`
- `save`
- `load`
- `reset`
- `map`

## Goal

Collect the flux core from the reactor core and use it at the command deck to repair the ship.
